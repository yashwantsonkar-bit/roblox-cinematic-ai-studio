# Security and permissions

- Never commit `.env`, API keys, OAuth tokens, cookies, or personal credentials.
- Review third-party Roblox models and scripts before insertion.
- Use a backup/copy of `.blend` and Roblox place files.
- Treat MCP tool calls as real actions in your open applications.
- Blender MCP can execute arbitrary Python inside Blender; connect only if you trust the server and keep sensitive files out of that session.
- Roblox Studio MCP can modify the open place. Do not connect to a production place without a backup.
- Require explicit approval before publishing, uploading, deleting, overwriting, or spending paid credits.
