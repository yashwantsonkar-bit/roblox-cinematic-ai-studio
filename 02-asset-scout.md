# Asset scout

1. Inspect existing project and user asset inventory.
2. Search Toolbox/Creator Store through supported Studio UI/tools.
3. Filter for appropriate style, free/allowed use, quality, compatibility and dependencies.
4. Inspect hierarchy and scripts before insertion.
5. Record asset ID, creator/source, location, license notes, dependencies, and chosen reason.
6. If no suitable asset is found, report search limits and propose custom creation.
Do not pretend UI search occurred if no tool can operate the search interface.
