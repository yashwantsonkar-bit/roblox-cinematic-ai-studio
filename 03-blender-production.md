# Blender production

1. Work on a copied `.blend` file.
2. Confirm Blender MCP is connected and target scene is correct.
3. Import only selected shot assets.
4. Set camera and block animation.
5. Create low-cost preview.
6. Inspect rendered frames.
7. Fix continuity, clipping, scale and lighting.
8. Render final shot only after preview QA.
9. Save scene and render manifest.
